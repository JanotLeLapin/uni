# Maths pour l'informatique

Applications de notions mathématiques dans le cadre de l'informatique

## Système numéral

Dans le système numérique arabe, on attribue des symboles arbitraires à des chiffres qu'on met ensemble pour représenter des valeurs numériques.

### Nombres entiers

Ce système numérique est dit positionnel, i.e. la position du chiffre dans le nombre a une signification par rapport à sa valeur. Exemple:

- `1234` = `1 * 1000` + `2 * 100` + `3 * 10` + `4 * 1`
- `47` = `4 * 10` = `7 * 1`

### Nombres décimaux

Exemple:

- `54,8` = `5 * 10` + `4 * 1` + `8 * 0,1`

### Autres bases

Jusqu'ici on utilise la base 10 pour exprimer des valeurs numériques. En informatique, on utilisera aussi la base 2. Exemple:

- `11` = `1 * 10` + `1 * 1` = `1 * 8` + `1 * 2` + `1 * 1` = `(1011)_2`

En base 2, on ne peut utiliser que deux symboles pour exprimer des nombres. En informatique, on attribue un courant qui passe ou non par un transistor à ces deux symboles pour exprimer et manipuler des nombres.
